# AGENTS.md — the paper

Scope: `tex/`. Read `/AGENTS.md` first.

## Generated vs. hand-written

| File | |
|---|---|
| `main.tex` | preamble, front matter, and the four `\input`s. Hand-written. |
| `01-literature.tex`, `02-admission.tex` | hand-written. `02-admission.tex` is the **authoritative** admission rule and audit standard — `CONTRIBUTING.md` summarizes it, not the other way round. |
| `references.bib` | hand-written; `bib_keys` in each `case.json` must resolve here. |
| `generated/ledger.tex`, `generated/refutations.tex` | **generated by `tools/build.py` — never edit.** Both carry a `% GENERATED` header. Edit the case's `case.tex` and run `make regen`. |
| `main.pdf`, `main.aux`, `main.log`, … | build output, gitignored. |

`generated/refutations.tex` emits, per case: the section heading (or a
subsection inside a group's shared section), the credit line, the context
prose, each statement quoted as posed, and then the `cxrefutation` region
inlined. All of it comes out of `counterexamples/<id>/case.tex`, which is why a
`cxrefutation` must contain **no** heading and **no** credit line of its own.
Nothing is `\input` per case any more, so a relative path written inside a case
resolves against `tex/` only by accident — don't write one.

## Compiling

```sh
cd tex && latexmk -pdf main      # or: make paper
make clean                       # latexmk -C
```

Compile from `tex/` — the `\input` paths assume it. On Overleaf, import the
whole repository and set the main document to `tex/main.tex`.

## Preamble facts worth knowing before you write LaTeX

- Bare `\cite` is `\citep` (`\AtBeginDocument{\let\cite\citep}`); use `\citet`
  where the authors are read as prose, and `\citeyearpar{...}` after a name
  already spelled out.
- `cleveref` is loaded: `\Cref{thm:...}`.
- Status macros: `\statusfalse`, `\statusproved`, `\statusnumeric`,
  `\statusconditional`, `\statusspeculative`. A refutation's theorem uses
  `\begin{theorem}[\statusfalse: ...]`.
- Math shorthands, already defined — do not redefine: `\R`, `\C`, `\tr`,
  `\per`, `\Imm`, `\diag`, `\Vol`, `\CE`, `\J`, `\disc`.
- Environments: `theorem` (numbered per section) with `proposition`, `lemma`,
  `corollary` sharing its counter; `problem`, `definition`, `example`, `audit`;
  `remark`.
- `problem` is boxed via `tcolorbox` **on purpose**: it holds statements quoted
  as originally posed, so the source's words can never be mistaken for ours.
  Do not put our own restatement inside a `problem`.
- `\casecredits{...}` is emitted by the build from the case's `cxcredits`
  region. Do not write it by hand.
- The `cx...` environments that structure `case.tex` are **not** LaTeX
  environments: `tools/build.py` extracts those regions and emits their contents,
  so nothing defines them in the preamble and the compiler never sees them.
  Their structure is checked by the build, which fails on an unclosed, nested,
  duplicated, or unknown region.

If a new macro is genuinely needed, add it to `main.tex`'s preamble rather than
defining it inside a case — the refutations are emitted in ledger order and a
local definition would leak to the ones after it.
