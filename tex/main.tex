\begin{abstract}
  This document reports GPT driven counterexamples to a number of conjectures, including well-known published conjectures as well as some plausible but less well-known ones. Given the asymmetry between proving a theorem and finding a counterexample, it is no surprise that both the literature and our list of counterexamples are growing rapidly. Supporting code is available at the companion repository: \href{https://github.com/suvrit/count-ex-machina}{\fontfamily{ppl}\selectfont\itshape https://github.com/suvrit/count-ex-machina}. Moreover, this repository welcomes contributions from the wider research community with the hope of kickstarting an \emph{``open source counterexample database.''}
\end{abstract}
